# esp-gate-opener
ESPHome 433mhz gate and garage opener for Home Assistant.


Parts list:
  1x any ESP32 (i used the xiao c5)
  1x FS1000A Transmitter
  1x MX-RM-5V Receiver (only if you dont have your gate code)
  1x 10K Ω Resistor
  1x 20K Ω Resistor (if you don't have the 20K resistor you can use 2+10K resistor setup like me)
